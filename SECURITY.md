# Security policy

## Reporting a vulnerability

Report security problems privately with [Report a vulnerability](https://github.com/FilipNone/OpenShifter/security/advisories/new) on the Security tab. Please don't open a public issue for them.

Say which part is affected (the firmware, the web tool or the command-line tools in `tools/`), which version you used, and how to reproduce the problem.

## Supported versions

Fixes go into the [latest release](https://github.com/FilipNone/OpenShifter/releases/latest). Older releases are not updated.
